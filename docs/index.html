方法论与口径（点击展开）
事件日 t0：目标利率生效日，由 FRED DFEDTAR（1982–2008）+ DFEDTARU（2008–今）自动探测，非人工录入。
基准：t0 前一交易日收盘——保证基准尚未反映新政。反应 = 第 n 个交易日后的值与基准之差。
窗口：按交易日计 1 日=1 / 10 日=10 / 1 月=21 / 3 月=63 / 6 月=126 / 1 年=252 日。
统计量：组内中位数（比均值稳健，避免单个极端事件主导）；鼠标悬停单元格可见 Q1/Q3 与有效样本数。
单位：价格类资产为 % 变化；国债收益率为 bp 变化；VIX 为绝对点数变化。
样本池：1994 年至今共 51 次加息（1985–1989 年碎步调整（6.25/12.5/43.75bp）已排除：幅度制式与 1994 年后的 25bp 框架不可比）。
主观 vs 客观：概率与触发条件为人工判断，需定期复核；反应矩阵为自动计算的客观结果。
