# FOMC 前瞻看板

按会议周期循环运行的**验证型**看板——不是"决议前夜截个图"，而是每场会议都留下
「事前怎么想 → 事后对不对」的可复算记录。

## 定位

| 不是 | 而是 |
|------|------|
| 一次性快照 | 循环运行的验证档案 |
| 引用别人的概率 | 每个数字都能自己复算 |
| 只展示结论 | 展示结论 + 触发条件 + 事后归因 |

## 核心产出

**一张图 + 一张表**：

- **图**：利率路径三条线——市场隐含（期货反算）／美联储 SEP 中值／上期 SEP，看分歧与漂移
- **表**：本场 vs 上场 vs 实际 的对比矩阵

## 数据源

| 来源 | 内容 | 认证 | 限制 |
|------|------|------|------|
| **CME 结算价 API** | 30 天联邦基金期货全曲线（60+ 合约） | 无需 | ⚠️ **只保留约 7 个交易日，必须每日抓** |
| **FRED CSV** | 政策利率、通胀、就业、流动性、金融条件、市场 | 无需 | 政策利率 1 天延迟 |
| Fed 官方 SEP PDF | 点阵图、经济预测 | 无需 | 需解析器 |
| CME FedWatch | 市场概率（加工后） | 无公开 API | ⚠️ 仅作交叉校验引用，**不可复算** |
| 一致预期 / 票委阵营 | 机构预测中值、鹰鸽判读 | — | 无结构化源，人工维护 |

CME 反算公式：`隐含利率 = 100 − settle`

## 目录结构

```
fomc-dashboard/
├── config/
│   ├── series.json      # FRED 序列清单 + CME 接口配置
│   └── meetings.json    # 会议日历 + 决议结果 + 票委名单（人工维护）
├── scripts/
│   ├── collect.mjs      # 采集器（CME + FRED → raw + 快照 + 派生）
│   └── daily.mjs        # 每日归档 + git 提交
├── data/
│   ├── raw/             # 最新原始数据
│   ├── snapshots/<日期>/ # 每日永久留档
│   └── derived/         # 派生指标（current.json）
├── docs/                # 看板产物
└── run-daily.cmd        # 计划任务启动器
```

## 用法

```bash
node scripts/collect.mjs                    # 抓全部
node scripts/collect.mjs --cme-only         # 只抓期货曲线
node scripts/collect.mjs --fred-only        # 只抓 FRED
node scripts/collect.mjs --date 09/21/2026  # 指定 CME 结算日
node scripts/daily.mjs                       # 采集 + 归档 + 提交
```

## 分层结构

|----|------|------|

| L6 政治与制度 | 选举倒计时、Fed 独立性 | 手工维护 |

## 时区约定

决议结果于会议最后一日美东 14:00 公布 = **SGT 次日 02:00**（夏令时）／**03:00**（冬令时）。
所有落盘时间戳统一用 SGT（+08:00）。
