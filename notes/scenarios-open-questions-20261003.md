## 待决 A｜A2「正常化」的第三条触发条件

### 现状

```json
"triggers": [
  "政策利率已显著高于中性估计（4.00% vs 中性 3.0–3.5%）",
  "就业温和而非过热：非农 3M 均值 50–150k（当前 +50.7k ✅，贴近下限）",
  "市场能预判下一步（期货曲线给出的路径与点阵图接近）"      ← 本条
],
"verdict": "…但与点阵图（2026 年末 4.10%）相比，市场的路径（峰值 2027-11、4.68%）明显更平缓——分歧就在这里。"
```

**表面矛盾**：触发条件说「与点阵图接近」，verdict 说「明显更平缓，分歧就在这里」——自相矛盾。

### 🔴 但复查后发现更严重的问题：这句话**方向和口径都错了**

**口径错**：拿「市场的**峰值**」去比「点阵图的 **2026 年末中值**」——两个不同 horizon、不同口径的东西。

**方向错**：按同 horizon 对齐后，市场**高于**点阵图，不是「更平缓」：

| horizon | SEP 官方 Median | 换中点口径 | 市场隐含 | 差 |
|---|---|---|---|---|
| 2026 年末 | 4.10 | 3.975 | **4.07**（DEC 26） | **+9.5bp** |
| 2027 年末 | 4.10 | 3.975 | **4.68**（NOV 27，流动性末日） | **+70.5bp** |
| 2028 年 | 3.90 | 3.775 | 峰值 **4.681** | **+90.5bp** |
| Longer run | 3.20 | 3.075 | — | — |

> 口径说明：SEP 官方表 1 的 Median 列 = 目标区间**上限**，减去 0.125 换成**中点**才能与 CME 的 EFFR 口径对比（见记忆库 SEP 口径条目）。

**⇒ 真实背离是「市场比点阵更鹰（远期更高）」，而 config 现在写的是「市场更平缓」——反了。**

### 三个选项

| 选项 | 做法 | 影响 | 成本 |
|---|---|---|---|
| **① 修正表述（推荐）** | 把第三条触发条件改成可判定的措辞：<br>`"市场能预判下一步（该年 12 月合约隐含利率与点阵图同 horizon 中值相差 < 25bp）"`<br>并把 verdict 的背离方向改为「市场在 2027 年及以后比点阵更鹰」 | 本条判 **❌**（2027 差 +70bp）→ A2 变为 2/3 触发 | 只改文案，零逻辑改动 |
| **② 判 ❌ 并进一步下调 A2 概率** | 在 ① 基础上，把 A2 从 0.36 再降（如 0.30），让出的权重给 A1 | 需重算 A 轴归一化 | 中 |
| **③ 删掉该条** | 把 A2 触发条件从 3 条减到 2 条（全满足） | A2 变成 2/2 = 1.00，**概率反而会上升** —— 与「背离」的事实相反，**不建议** | 低但会误导 |

> **建议 ①**。理由：「市场能否预判」本身是 A2 定义（「例行公事、可预期」）的核心判据，不该删；但必须换成能算的判据，否则永远无法证伪。修完之后 A2 = 2/3，正好对应我这次已填入的 0.36 权重 —— **数字不用动，只改文案**。

## 待决 B｜C 轴的问法

### 现状

```json
"axisC": {
  "question": "这轮最终加到哪？",                       ← 问的是【终点水平】
  "note": "历史样本按所属周期的「累计加息幅度」自动分组",   ← 分组用的是【累计幅度】
  "groups": [
    { "id": "C1", "definition": "自 4.00% 起再加 ≤100bp，终点 ≤5.00%", "filter": { "maxTotalBp": 200 } },
    …
  ]
}
```

**问题**：问水平、却按幅度分组 → 同组内终点水平可以差很远。

### 实测：同组内终点水平差多少

| 周期 | 累计 bp | 起点上限 | 终点上限 |
|---|---|---|---|
| 1997 | 25 | 5.25 | 5.50 |
| 1999–2000 | 175 | 4.75 | 6.50 |
| 1994–95 | 300 | 3.00 | 6.00 |
| 2015–18 | 225 | 0.25 | 2.50 |
| 2004–06 | 425 | 1.00 | 5.25 |
| 2022–23 | 525 | 0.25 | 5.50 |

- **C2 组**（200–400bp）= 1994–95 终点 **6.00%** ／ 2015–18 终点 **2.50%** → **差 3.50pp**
- **C3 组**（>400bp）= 2004–06 终点 5.25% ／ 2022–23 终点 5.50% → 差 0.25pp（这组反而一致）

### 🔴 关键发现：按「终点水平」重新分组是**不可行的**

把 6 轮周期的终点列出来：

```
5.375  6.375  5.875  2.375  5.125  5.375   （中点口径，%）
```

**6 轮里 5 轮终点落在 5.1–6.4%**，只有 2015–18（2.375%）是异类。按终点分 3 档 → 一档塞 5 个、另外两档各 0–1 个，**完全无区分度**。

换成「终点相对中性利率（3.0–3.5%）的偏离」也一样：5 轮都在 +1.6~+3.4pp，只有 2015–18 是负值。

> ⇒ 历史样本的终点水平**天然聚集**，因为过去 6 轮几乎都是从低利率起跑到相似的终点。**问题不在问法，而在样本本身没有水平维度的方差。**

### 因此只剩两条路

| 选项 | 做法 | 评价 |
|---|---|---|
| **① 改问法（推荐）** | `question` 改「**这轮还会再加多少？**」；三条 definition 从「终点 ≤5.00%」改成「自当前起再加 ≤100bp / 100–200bp / >200bp」。分组口径（累计幅度）与问法口径**完全对齐** | 零计算改动、零样本浪费；代价 = 不再直接回答「终点在哪」（但终点可由「当前 4.00 + 再加幅度」自行换算） |
| **② 保留现有分组，但把样本的起止水平亮出来** | 在 C 轴卡片加一行「本组样本：起点 → 终点」，并注明「本组回答的是**幅度**、不是**水平**；水平请用 4.00% + 本组幅度换算」 | 可与 ① 叠加。纯展示层改动，需动 `build-dashboard.mjs` |

**建议 ① + ②**：① 解决口径不一致的根本问题，② 补回读者真正关心的水平信息。

### ⚠️ 附带影响
现在 C 轴概率（58/31/11）是按 **终点水平分档**（≤5.00 / 5.00–6.00 / >6.00）算的。若采纳 ①，定义改成幅度口径后**数值恰好不变**——因为当前起点 4.00 与档位边界 5.00/6.00 正好相差 100bp/200bp，两套口径在**本轮**数值等价。所以 ① 不需要重算概率。
